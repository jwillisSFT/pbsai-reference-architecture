# PBSAI Security Policy

## Reporting a Vulnerability

Please do not report exploitable vulnerabilities or sensitive security
information through public GitHub Issues.

Use GitHub Private Vulnerability Reporting for this repository whenever
possible.

If private vulnerability reporting is unavailable, contact:

research@agcp.ai

Please include sufficient information to evaluate the reported condition,
including the affected PBSAI artifact or version, relevant architecture
component or control, expected behavior, observed behavior, and potential
security impact.

## Architecture Security Concerns

Public architectural, control-design, interoperability, or specification-level
security questions that do not disclose an exploitable vulnerability may be
submitted through the PBSAI Architecture Review issue form.

## Supported Baseline

Security review should normally be performed against the current published
PBSAI architecture and control artifacts unless the report specifically
concerns an earlier version.

## Disclosure

Please allow the PBSAI maintainers reasonable opportunity to investigate and
address a reported vulnerability before public disclosure.
